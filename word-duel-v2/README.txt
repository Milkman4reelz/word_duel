WORD DUEL 2.0
Install Node.js from https://nodejs.org. Open Terminal in this folder and run node server.js. Visit http://localhost:3000. For internet play, deploy this folder to a Node web host (for example Render as a Node web service, build command npm install, start command npm start). Both players open the same hosted HTTPS URL. Create a room and share its code. Rooms and scores are in memory and reset on server restart. Scores: 100 per solved word, 50 bonus for completing the list. Hints use WORD | hint syntax. Timer and guess limit are optional. Chat and scoreboard are room-only. Sound depends on browser audio permissions. No accounts or global persistent leaderboard.
